# 한국어 · English · 日本語

상단 언어 메뉴로 한국어, 영어, 일본어를 선택합니다. 처음 방문할 때는 한국어이며, 선택은 `ma-language-v1`에 저장됩니다. 저장소 접근이 제한되어도 현재 페이지에서 전환할 수 있습니다. 다른 탭에서 변경한 언어도 반영합니다.

## 수정할 파일

- `js/locales.js`: 한국어 원문을 키로, `[영어, 일본어]` 문구를 관리합니다. 화면에 문구를 추가하면 이 사전에도 추가하세요.
- `js/i18n.js`: 언어 메뉴, 날짜·인원·금액 등 가변 문구, 텍스트·접근성 속성의 전환을 담당합니다. 새로 렌더링한 UI는 MutationObserver로 번역합니다. 노드를 교체하지 않아 폼 입력값과 이벤트 연결을 유지합니다.
- `css/language.css`: 작은 언어 메뉴와 언어별 줄바꿈·사진 확대 안내를 관리합니다.

`index.html`에서 사전과 전환 스크립트를 다른 기능보다 먼저 불러옵니다. 언어별 화면의 기준 데이터는 한국어 원문이며, 지역 ID·필터 값·일정 데이터·링크는 번역하지 않습니다. 지역 검색은 세 언어 이름을 모두 지원합니다.

사용자가 작성한 일정 이름·장소·메모와 이메일에는 `translate="no"`를 적용합니다. 새로 수정한 이름·메모는 `customTitle`, `customName`, `customNote`로 구분합니다. 기존 데이터에서 자동 생성한 제목·기본 장소는 원문과 비교해 표시만 번역하며, 저장된 원문은 바꾸지 않습니다. 새로 사용자 내용을 표시하는 요소에도 `translate="no"`를 적용하세요. 브라우저 confirm/prompt 문구에는 `MA_I18N.t()`를 사용합니다.

사진을 다른 화면에 복제할 때 `MA_I18N.cloneSource()`를 사용하면 현재 표시 언어가 아닌 원문을 기준으로 복제하여 이후 전환도 유지합니다. 지역명·장소명·사진 설명의 원문은 별도 data 속성에 보관합니다.

## 범위와 확인

지역 탐색, 18개 지역 사진과 설명, 풍경 실험, 제작 기록, 여행 계획·편집·공유, 보관함, 계정 UI를 번역했습니다. 번역 문구는 생성형 AI가 작성·검토한 로컬 사전입니다. 외부 번역 서비스로 입력 내용을 전송하지 않습니다. 원어민 감수는 하지 않았으며 고유명사 표기는 추가 검토할 수 있습니다.

금액은 모든 언어에서 **한국 원화(KRW)**입니다. 환율 계산은 하지 않습니다. JSON·ICS 내보내기는 저장된 원문을 유지합니다. 외부 지도·관광·사진 원문 페이지, 인증 이메일과 브라우저 자체 메시지는 이 사이트의 언어 전환 범위에 포함되지 않습니다.

2026-09-09에 실제 페이지와 스크립트를 LinkeDOM 환경에서 확인했습니다: 한국어→영어→일본어→한국어 전환, 일본어 설정으로 시작, 원본 폼 값과 사용자 제목 유지, 세 언어 지역 검색, 18개 지역 ID 보존, 사진 복제·확대·풍경 실험 연결, 일정 생성·저장·삭제·되돌리기·공유·계정 전환, 보관함 사진·저장·해제. 실제 iPhone Safari의 시각 검수나 새로운 실계정 인증 시험은 수행하지 않았습니다.

기존 Google OAuth와 메일 발송의 관리자 설정 필요 여부, Vercel의 배포 보호 설정은 언어 UI 변경으로 해결되지 않습니다. 별도 확인 없이 완료로 표시하지 마세요.
