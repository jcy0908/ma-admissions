# MA Admissions — HTML/CSS/JavaScript 데모

## 콘셉트

- **브랜드명:** MA Institute of Design
- **MA의 의미:** 間(마, 여백·간격) + Material + Mind
- 교토 가레산스이(枯山水)의 여백, 안도 다다오의 빛과 콘크리트, 르메르·질 샌더·COS의 절제,
  이세이 미야케의 구조, Apple·Toss의 명료함, Sony·B&O의 정밀함을 한 화면 언어로 정리했습니다.
- 특정 브랜드를 그대로 복제하지 않고, 공통된 미학을 재해석한 독립 디자인입니다.
- 캠퍼스는 강원 영서(嶺西) 원주로 설정했으며, 색은 영서의 풍경에서 왔습니다.

## 팔레트 — 영서의 풍경

```css
:root {
  --yeongseo-fog: #E7E6E0;  /* 아침 안개 */
  --dry-field: #B8AE9E;     /* 마른 논 */
  --mountain-ink: #252A27;  /* 먹색 산 */
  --moss: #59665A;          /* 이끼 */
  --stone: #8D8B84;         /* 돌 */
  --winter-soil: #6A5F53;   /* 겨울 흙 */
  --paper: #F3F1EA;         /* 한지 */
}
```

## 실행

1. 폴더를 VS Code 또는 Claude Code에서 엽니다.
2. `index.html`을 브라우저에서 열거나 VS Code Live Server를 사용합니다.
3. 별도 빌드 과정이나 프레임워크가 필요 없습니다.

## 포함 기능

- 모바일 우선 반응형 레이아웃
- 3단계 지원 폼
- 글자 수 카운터 (지원 동기 300자, 에세이 최소 500자 / 최대 2000자)
- PDF 파일명 및 용량 검증 (최대 200MB)
- localStorage 자동 저장 및 복원
- 단계 이동과 간단한 유효성 검사
- 제출 완료 다이얼로그 (`<dialog>`)
- 접근성용 aria 속성 (aria-live 카운터·저장 배너, role="alert" 오류)
- 라이트/다크 모드 (`prefers-color-scheme`)

## Claude Code에 이어서 요청할 프롬프트

아래 문장을 그대로 붙여 넣으면 됩니다.

> 이 프로젝트의 기존 미니멀 디자인 언어는 유지해줘. Supabase를 연결해 지원서 텍스트와 파일을 실제 저장하고, 관리자만 볼 수 있는 `/admin` 페이지를 추가해줘. 업로드 진행률, 서버 측 유효성 검사, 개인정보 동의 체크박스, 제출 마감 시간 검증도 구현해줘. 기존 HTML/CSS/JavaScript 구조를 최대한 유지하고 변경한 파일과 이유를 마지막에 정리해줘.

## 주의

현재 버전은 프론트엔드 데모입니다. 제출 내용은 서버로 전송되지 않으며, 브라우저의
localStorage에만 저장됩니다. 실제 개인정보와 파일을 받으려면 백엔드, 저장소, 인증,
개인정보처리방침이 필요합니다.
