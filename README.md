# MA — 강원도를 인터페이스로 번역한 웹 스터디

강원특별자치도 18개 시군을 산과 바다 두 장의 관광 이미지로 압축하지 않고,
공개 사진과 지형 자료에서 읽은 색·간격·경계·리듬을 반응형 웹의 규칙으로
번역한 자발적 디자인 케이스 스터디입니다.

> 서로 다른 조건을 가진 강원도의 18개 지역을 하나의 인터페이스 언어로 번역할 수 있을까?

## 범위

- 18개 시군에 대한 짧은 디자인 해석
- 출처와 라이선스를 개별 표기한 Wikimedia Commons 사진 9장
- HTML과 CSS로 그린 형태 연구 6개와 합성 장면 1개
- 겨울 안개, 얼음, 먹색, 이끼, 돌, 흙, 유리로 구성한 재료 7개
- 프레임워크 없이 작성한 HTML, CSS, JavaScript

지역을 묶는 방식과 `물 / 지형 / 경계 / 리듬 / 재료` 렌즈는 공인된 지리 분류가
아니라 이 프로젝트가 화면의 규칙을 찾기 위해 사용한 해석입니다.

## 페이지 구성

1. **Project brief** — 질문, 범위, 제약, 산출물, 자료
2. **Place** — 백두대간을 경계가 아닌 연결 구조로 다시 읽기
3. **Translation** — 안개·능선·이끼·서리·탄광 기억·동해안을 UI 규칙으로 변환
4. **Evidence chain** — 근거 → 해석 → 결정 → 실제 구현
5. **Translation lab** — 투명도, 간격, 1px 선, 강조색 빈도를 직접 조절
6. **Drawings** — CSS만으로 만든 여섯 형태 연구와 한 개의 합성 장면
7. **Regions** — 18개 지역을 프로젝트의 디자인 렌즈로 탐색
8. **Materials / Concept** — 일곱 재료와 세 개의 설계 원칙
9. **Alternatives / Critique** — 비교한 방향, 가장 잘된 선택, 한계, 다음 질문
10. **Authorship** — 제작 범위, 공개 사진, 생성형 AI 사용 범위 공개

## 디자인 시스템

```css
:root {
  --paper: #EEF1F2;      /* 겨울 안개 */
  --paper-deep: #DBE2E4; /* 성엣장 */
  --ink: #1C2325;        /* 탄광 기억을 번역한 먹색 */
  --accent: #4B6560;     /* 이끼 — 유일한 유채색 */
  --stone: #8A9296;      /* 돌 */
  --soil: #5D6A6D;       /* 겨울 흙 */
}
```

헤더는 안개가 뒤의 정보를 지우지 않고 선명도만 낮추는 성질을 반투명 표면과
`backdrop-filter`로 구현합니다. 이를 지원하지 않거나 투명도 축소를 선호하는
환경에서는 불투명한 배경으로 대체됩니다.

## 인터랙션과 접근성

- 시스템 글꼴(`-apple-system` / SF 계열 우선)만 사용해 외부 폰트 요청 없이 운영체제의 한글 글꼴로 자연스럽게 대체
- `Translation`의 긴 호흡을 CSS `position: sticky`와 작은 시선 이동으로 구성하고, `requestAnimationFrame`을 `IntersectionObserver`로 화면 안에서만 갱신
- 스크롤 중인 장을 공통 내비게이션의 `aria-current`로 표시하고, 헤더는 내용이 겹칠 때만 반투명 스크롤 엣지를 표시
- 재료 견본의 포인터 드래그, 속도 인계, 스프링 스냅과 키보드 방향키 이동
- 네 개의 네이티브 range control을 사용하는 Translation Lab과 초기화 버튼
- `aria-pressed` 버튼과 `aria-live` 결과를 사용하는 지역 디자인 렌즈 필터
- 모바일에서도 사라지지 않는 가로 스크롤 섹션 내비게이션
- 본문 바로가기, 명확한 포커스 표시, 의미 있는 제목 구조와 이미지 대체 텍스트
- 라이트·다크 모드, 고대비, 모션 축소, 투명도 축소, 인쇄 스타일 대응
- JavaScript가 꺼져도 모든 본문과 지역 정보가 보이는 점진적 향상 구조

사진은 원본 JPEG를 폴백으로 남기고, 640·960·1200px WebP 파생본을 `<picture>`,
`srcset`, `sizes`로 선택합니다. 모든 본문 이미지는 고유 크기를 유지한 채 지연 로드되어
레이아웃 이동과 불필요한 전송량을 줄입니다.

## 실행

빌드 과정과 패키지 설치가 필요 없습니다.

```text
index.html을 브라우저에서 열기
```

ES module을 로컬 파일 정책 때문에 불러오지 못하는 브라우저에서는 프로젝트 루트에서
간단한 정적 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

## 자료와 저작권

사진 9장의 저작자, 라이선스, 원문 링크는 페이지의 각 캡션과
[`CREDITS.md`](./CREDITS.md)에 기록했습니다. 지역별 문장은 공개 자료를 바탕으로 한
프로젝트의 편집적 해석이며, 여행·행정·지리 안내 자료로 사용하기 위한 것이 아닙니다.

지역 지리 표현 일부를 검토할 때 강원특별자치도의 [행정구역](https://state.gwd.go.kr/portal/introduce/situation/district)과
[위치·지세](https://state.gwd.go.kr/portal/introduce/situation/position),
[태백시 발원지 안내](https://tour.taebaek.go.kr/tour/),
[철원군 지형](https://www.cwg.go.kr/www/contents.do?key=232) 등 공식 자료를 참고했습니다.
페이지의 디자인 렌즈와 화면 번역은 공인 분류가 아니라 제작자의 편집 판단입니다.

## 제작 및 생성형 AI 사용

- 프로젝트 주제, 요구사항, 최종 승인: **정찬용**
- 구조·문장·코드: 생성형 AI 보조를 받아 제작
- 최종 판단과 승인: 제작자

생성형 AI를 사용하지 않은 단독 제작물로 주장하지 않습니다. 사진 역시 제작자가 직접
촬영한 것으로 주장하지 않으며, 모든 공개 이미지의 출처를 개별 표기합니다.
