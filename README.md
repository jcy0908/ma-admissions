## 팔레트 — 영서의 겨울

따뜻한 크림/베이지 계열을 걷어내고, 겨울 영서의 회청색으로 다시 채집했습니다.
여섯 색은 사실상 무채색에 가깝고, 이끼색 하나만 색을 가집니다.
그래서 이끼색이 나타나는 자리가 곧 눌러야 할 곳이 됩니다.

```css
:root {
  --winter-haze: #EEF1F2;   /* 겨울 안개 */
  --ice-sheet:   #DBE2E4;   /* 성엣장 */
  --mountain-ink:#1C2325;   /* 먹색 산 */
  --moss:        #4B6560;   /* 이끼 — 유일한 색 */
  --stone:       #8A9296;   /* 돌 */
  --winter-soil: #5D6A6D;   /* 겨울 흙 */
}
```

### 일곱 번째 재료 — 유리

안개 낀 아침 창처럼, 뒤가 비치되 흐리게. 헤더, 가레산스이 마당, 세 개의 기둥,
입력창, 요약, 다이얼로그가 모두 유리 한 장입니다. 배경에는 고정된 안개 세 덩어리가
깔려 있고(움직이지 않습니다), 그 위를 유리가 덮습니다.

```css
--glass-bg:     rgba(255, 255, 255, 0.5);
--glass-border: rgba(255, 255, 255, 0.65);
--glass-blur:   blur(22px) saturate(150%);
```

`backdrop-filter`를 지원하지 않는 브라우저에서는 `@supports`로 불투명도를 올려
가독성을 지킵니다.

## 실행

1. 폴더를 VS Code 또는 Claude Code에서 엽니다.
2. `index.html`을 브라우저에서 열거나 VS Code Live Server를 사용합니다.
3. 별도 빌드 과정이나 프레임워크가 필요 없습니다.

## 포함 기능

- 모바일 우선 반응형 레이아웃
- 3단계 지원 폼
- 글자 수 카운터 (지원 동기 300자, 에세이 최소 500자 / 최대 2000자)
- PDF 파일명 및 용량 검증 (최대 200MB)
- localStorage 자동 저장 및 복원
- 단계 이동과 간단한 유효성 검사
- 제출 완료 다이얼로그 (`<dialog>`)
- 접근성용 aria 속성 (aria-live 카운터·저장 배너, role="alert" 오류)
- 라이트/다크 모드 (`prefers-color-scheme`)
- 글라스모피즘 레이어 + `backdrop-filter` 미지원 폴백

## 유동적 인터페이스

`js/fluid.js`는 외부 라이브러리 없이 스프링·속도 인계·모멘텀 투영·러버밴딩을
구현합니다. Apple의 *Designing Fluid Interfaces*(WWDC 2018) 원칙을 웹으로 옮긴
최소 구현이며, 페이지에서 이렇게 쓰입니다.

- **진행 바** — 단계를 오갈 때 CSS transition 대신 스프링이 움직입니다.
  transition은 도중에 붙잡을 수 없기 때문입니다.
- **제출 시트** — 아래에서 올라오고, 같은 길로 내려갑니다. 손가락으로 잡아
  내릴 수 있고, 내리는 도중에 다시 잡으면 그 자리에서 따라옵니다.
  놓은 지점이 아니라 속도로 예측한 도달점을 보고 닫을지 되돌릴지 정합니다.
  천천히 조금만 끌고 놓으면 되돌아오고, 짧아도 빠르게 던지면 닫힙니다.
- **색 견본** — 좁은 화면에서 옆으로 끕니다. 양 끝에서는 딱 멈추지 않고
  저항이 커집니다(러버밴딩). 키보드 좌우 방향키로도 넘길 수 있습니다.
- **모든 반응은 `pointerdown`에서** 시작합니다. `click`을 기다리면 죽은 것처럼
  느껴집니다.

`prefers-reduced-motion`이 켜져 있으면 스프링과 드래그를 끄고 즉시 상태를
바꿉니다. 움직임을 줄이는 것이지 피드백을 없애는 것이 아닙니다.
